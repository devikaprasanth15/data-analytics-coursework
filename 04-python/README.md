# Python Fundamentals – Strings & Tuples

## Overview

This assignment covers the basic concepts of **Strings and Tuples** in Python.

## What I Learned

### Strings

* String concatenation using `+`
* Taking string input using `input()`
* Accessing characters using indexing
* String slicing
* Reversing a string using slicing
* Using string methods such as:

  * `.upper()`
  * `.lower()`
  * `.capitalize()`
  * `.count()`
  * `.replace()`

### Tuples

* Creating tuples
* Concatenating tuples using `+`
* Repeating tuples using `*`
* Accessing elements using indexing
* Accessing parts of a tuple using slicing
* Python indexing starts from **0**

## Key Concepts

* **Indexing:** Used to access individual elements.
* **Slicing:** Used to access a range of elements.
* **Concatenation:** Joining strings or tuples together.
* **String methods:** Used to modify or work with strings.
* **Tuples:** Ordered collections of values that can be accessed using indexes.
