 Module 1: Excel for Data Analytics

Welcome to my Excel learning repository! This folder tracks my hands-on practice, assignments, and projects covering fundamental spreadsheet techniques, data cleaning, statistical analysis, advanced formulas, and interactive dashboard creation.

---

##  What I Learned

### 1. Fundamentals & Statistics
- **Excel Basics:** Navigating the interface, data entry, sheet management, importing data, and table creation.
- **Data Analytics Lifecycle:** Understanding data types and the core stages of analytics.
- **Statistics Basics:** Calculating Mean, Median, Mode, Variance, and Standard Deviation using built-in formulas and the **Analysis ToolPak**.

### 2. Core Formulas & Text Processing
- **Aggregation Formulas:** `SUM()`, `AVERAGE()`, `MIN()`, `MAX()`, `COUNT()`
- **Conditional Logic:** `IF()`, `SUMIF()`, `COUNTIF()`, `AVERAGEIF()`
- **Text Manipulation:** `LEFT()`, `RIGHT()`, `MID()`, `UPPER()`, `LOWER()`, `PROPER()`
- **Date & Time Functions:** `TODAY()`, `NOW()`, `YEAR()`, `MONTH()`, `WEEKDAY()`, `DATEDIF()`

### 3. Data Cleaning & Power Query
- Cleaning missing values, removing duplicates, and fixing inconsistent data.
- Utilizing **Power Query** for data transformation, splitting/merging columns, and Flash Fill.
- Removing trailing spaces, setting up Data Validation, and applying Conditional Formatting.

### 4. Advanced Lookup & Pivot Tables
- **Lookup Functions:** `VLOOKUP`, `HLOOKUP`, `XLOOKUP`, and `INDEX-MATCH`.
- **PivotTables & PivotCharts:** Summarizing datasets, connecting relational tables, and using Slicers for dynamic filtering.

### 5. Data Visualization & AI Tools
- **Charts:** Bar, Line, Pie, Column, Scatter, Combo charts, and Sparklines.
- **AI Integration:** Leveraging AI tools for formula generation, automated summaries, and quick visual insights.
