#  Module 3: SQL for Database Management & Data Analytics

Welcome to my SQL learning directory! This folder tracks my coursework, assignments, and practical scripts covering relational databases, data manipulation, advanced queries, window functions, and database design using MySQL Workbench.

---

##  Syllabus & Key Learnings

### 1. Database Fundamentals & Architecture
- **RDBMS Concepts:** Introduction to databases, tables, records, fields, datatypes, and Normalization principles.
- **Keys & Constraints:** Primary Key (PK), Foreign Key (FK), Candidate Key (CK), Composite Key, `NOT NULL`, `UNIQUE`, `CHECK`, `DEFAULT`, and `AUTO_INCREMENT`.
- **SQL Command Subsets:** Understanding DDL, DML, DCL, and TCL operations.

### 2. DDL & DML Operations
- **Data Definition Language (DDL):** `CREATE`, `ALTER`, `RENAME`, `TRUNCATE`, and `DROP`.
- **Data Manipulation Language (DML):** `INSERT`, `SELECT`, `UPDATE`, and `DELETE`.
- **Core Differences:** Comparing `DROP` vs. `TRUNCATE` vs. `DELETE`.

### 3. Data Querying, Filtering & Joins
- **Filtering & Clauses:** `DISTINCT`, `WHERE`, `ORDER BY`, `LIMIT`, `BETWEEN`, `IN`, `LIKE` (pattern matching), and `IS NULL` / `COALESCE()`.
- **Aggregations:** `GROUP BY`, `HAVING`, and aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`).
- **Joins & Set Operations:** `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL OUTER JOIN`, `CROSS JOIN`, `SELF JOIN`, `UNION`, and `UNION ALL`.

### 4. Advanced SQL & Database Objects
- **Window Functions:** `ROW_NUMBER()`, `RANK()`, `DENSE_RANK()`, `LEAD()`, `LAG()`, combined with `PARTITION BY`.
- **Subqueries & CTEs:** Single-row, multi-row, correlated subqueries (`EXISTS` / `NOT EXISTS`), and Common Table Expressions (`WITH` clause).
- **Control Flow & Objects:** `CASE` statements, Stored Procedures, User-Defined Functions, Views, Indexes, and Triggers.
- **AI Integration:** Leveraging Text-to-SQL tools to streamline query generation from natural language.
