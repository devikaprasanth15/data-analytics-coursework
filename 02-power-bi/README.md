# Module 2: Power BI for Business Intelligence & Visual Analytics

Welcome to my Power BI repository folder! This space showcases my progress from data connection and Power Query ETL transformations to Star Schema data modeling, advanced DAX measures, interactive reporting, and end-to-end Mini Project deliverables.

---

##  Syllabus & Key Learnings

### 1. Fundamentals & Power Query (ETL)
- **Power BI Ecosystem:** Desktop installation, interface exploration, and data source connections.
- **Power Query Transformations:** Importing datasets, filtering rows, handling missing/duplicate records, merging/appending queries, and grouping/aggregating data.

### 2. Data Modeling & Star Schema
- **Relational Concepts:** Understanding normalization vs. denormalization.
- **Data Architecture:** Building clean **Star Schemas**, managing table relationships, setting **Cardinality** (1:1, 1:Many, Many:Many), and configuring cross-filtering directions.

### 3. DAX (Data Analysis Expressions)
- **Calculated Columns vs. Measures:** Understanding context (Row Context vs. Filter Context).
- **Core Functions:** Mathematical, Logical, Statistical, and Text functions.
- **Advanced DAX:** Date & Time Intelligence functions, Ranking, Top N analysis, and time-series calculations.

### 4. Data Visualization & Dashboard Design
- **Visual Palette:** Bar, Column, Line, Area, Pie, Donut, Scatter, Table, Matrix, Tree Map, Maps, Combo charts, KPIs, and Gauge visuals.
- **Interactivity:** Slicers, dynamic filters, matrix hierarchies, conditional formatting, data bars, drill-downs, dynamic buttons, and bookmarks.
- **AI Visuals & Features:** Smart Narratives, Key Influencers, Q&A visual for natural language query generation, and "Analyze" via right-click.
