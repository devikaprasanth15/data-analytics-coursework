#  Hospital Performance Power BI Dashboard

An interactive Power BI dashboard designed to analyze hospital performance metrics, patient wait times, bed occupancy rates, and overall healthcare operational efficiency.

##  Project Overview
- **Objective:** Track and analyze key healthcare performance indicators (KPIs) to improve patient care and resource allocation.
- **Tools Used:** Power BI Desktop, Power Query, DAX, Excel.

##  Key Features & Deliverables
- **Data Transformation:** Cleaned patient and operational data using Power Query.
- **Data Modeling:** Established relational schemas between patient records, department details, and timelines.
- **DAX Calculations:** Created dynamic measures for average wait times, bed occupancy percentages, and patient readmission rates.
- **Visuals:** Included KPI cards, line charts for patient trends, bar charts for department loads, and interactive slicers.
